# Piyush Biswal | Portfolio Website

A simple personal portfolio website built with plain **HTML** and **CSS**. It introduces me, shows my education and skills, links to my Codeforces profile, and has a contact form.

## Features
* Sticky header with links that jump to each section
* Hero section with my photo and a short introduction
* About, Education, and Skills sections
* Competitive Programming section linking to my Codeforces profile
* Contact section with email, GitHub, and LinkedIn links
* Contact form with Name, Email, and Message fields
* Dark theme with high-contrast text so it is easy to read
* Responsive layout that also works on phone screens

---

## Built With
* **HTML** for the page structure
* **CSS** for styling, layout (flexbox), hover effects, and a mobile media query

## How to Run Locally
1. **Clone the repository:**
   ```bash
   git clone https://github.com/piyushpbiswal/YOUR_REPO_NAME.git
   cd YOUR_REPO_NAME
   ```

2. **Open the website:**
   Double-click `index.html`, or right-click it and choose "Open with" your browser.

No installation or build step is needed. Keep `index.html`, `style.css`, and `photo.png` in the same folder.

---

## Notes on the Contact Form
The form has no backend. When someone clicks "Send message", it opens their email app with the message ready to send to my email address.
